# 도시운영 AI 공개 데모

성남시 도시운영 AI 서비스의 화면 구조와 더미 상호작용을 확인하기 위한 정적 프론트엔드입니다. 모든 수치와 응답은 미리 작성된 예시이며 실제 행정 데이터, 백엔드 API, 모델을 사용하지 않습니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 Vite가 안내하는 로컬 주소를 엽니다.

## 검증

```bash
npm run check
npm run build
```

`check`는 필수 화면 요소와 이미지 자산을 확인하고, 네트워크 호출이나 인증 정보처럼 공개 저장소에 포함하면 안 되는 패턴이 없는지 검사합니다.

## 공개 범위

- 포함: 화면 레이아웃, 목업 아이콘과 이미지, 반응형 스타일, 더미 대화 흐름
- 제외: 실제 데이터 연동, API와 인증, 모델 호출, 데이터 처리·예측 로직, 내부 운영 문서
