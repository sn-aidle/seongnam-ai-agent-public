# seongnam-ai-agent-public

성남시 도시운영 AI 프로젝트의 공개용 소스코드 저장소입니다.

현재 공개 범위는 실제 데이터나 AI 모델을 연결하지 않은 프론트엔드 더미 데모입니다. 목업과 동일한 화면 구조, 아이콘, 반응형 레이아웃과 예시 상호작용을 확인할 수 있습니다.

## 시작하기

```bash
cd frontend
npm install
npm run dev
```

검증 명령은 다음과 같습니다.

```bash
npm run check
npm run build
```

자세한 범위는 [프론트엔드 안내](frontend/README.md)를 확인해 주세요. 작업 요구사항과 수용 기준은 GitHub Issue #1에서 관리합니다.
