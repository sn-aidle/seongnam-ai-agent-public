# 도시운영 AI PoC

공개용 `frontend/index.html`과 이미지 자산을 그대로 복사한 정적 목업입니다. 모든 수치와 응답은 예시이며 실제 분석/API 호출은 없습니다.

- 배포: https://sn-aidle.github.io/seongnam-ai-agent-public/poc/
- GitHub Actions: `.github/workflows/pages.yml`
- 목업 갱신 시 `frontend/index.html`과 `frontend/public/` 자산을 이 폴더에도 반영합니다.

로컬 확인: 저장소 루트에서 `python3 -m http.server 8000` 실행 후 `http://localhost:8000/poc/`에 접속합니다.
