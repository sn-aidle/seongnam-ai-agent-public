# 공개 아키텍처 개요

```text
frontend   정적 도시운영 AI 목업과 더미 상호작용
backend    Spring Boot 애플리케이션 실행 골격
data       외부 연동 없는 합성 예제
ml         비공개 ML 모듈의 경계 설명
```

공개 저장소는 각 모듈의 존재와 실행 환경만 보여줍니다. 실제 서비스에서는 모듈 사이에 계약과 구현이 존재하지만, 다음 정보는 이 저장소의 범위 밖입니다.

- 실제 데이터 원천의 식별자, 좌표, 호출 조건과 수집 주기
- 데이터 정규화·적재·과거 시점 조회 방식
- Agent의 도구 선택, 판단과 응답 조합 방식
- 모델 입력 feature, 학습·평가·추론과 설명 방식
- 인증, 운영 인프라, 장애 복구와 배포 설정

공개 화면과 예제는 실제 시스템의 결과를 재현하지 않으며 모두 더미로 표시합니다.
